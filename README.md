# Pupille

Pupille is an iOS photo feed designed for ETHGlobal Tokyo's World track. It aims to let a viewer verify the exact image bytes, an app attestation, and the World-backed pseudonymous author of a post.

**Current state:** the iPhone app has World-first onboarding, a native IDKit Proof of Human request, App Attest registration, a persistent Secure Enclave profile key, camera capture, publication, a rounded photo feed, and a social profile with signed avatar uploads. The feed checks downloaded image bytes and signatures against a pinned issuer key. The backend uses PostgreSQL and verifies World proofs through the Developer Portal. Staging Human signup has passed on a real iPhone; publishing, feed, and avatar persistence still need an end-to-end iPhone run. Follow the [MVP iPhone guide](docs/IPHONE_MVP_TESTING.md) for the current build and its exact trust limits. The [MVP follow-up list](docs/TODO.md) tracks remaining device checks. The earlier [device testing guide](docs/IPHONE_TESTING.md) documents the checks that already passed.
